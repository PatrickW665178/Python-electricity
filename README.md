# Python-electricity# 電力需求預測模型

## 專案簡介

本專案旨在利用機器學習模型預測台灣的電力需求。程式碼讀取包含電力相關特徵的 CSV 檔案，並使用四種不同的迴歸模型（決策樹、隨機森林、極限梯度提升和支持向量回歸）進行預測。專案包括資料的載入、前處理、模型訓練、超參數調整、模型評估以及結果的可視化。

## 模型與方法

本專案使用了以下四種迴歸模型進行電力需求預測：

* **決策樹 (Decision Tree, CART):** 一種基於樹狀結構進行決策的模型。
* **隨機森林 (Random Forest):** 一種集成學習方法，透過建立多個決策樹並取其平均預測結果來提高預測準確性。
* **極限梯度提升 (Extreme Gradient Boosting, XGBoost):** 一種高效且廣泛使用的梯度提升演算法。
* **支持向量回歸 (Support Vector Regression, SVR):** 一種基於支持向量機 (SVM) 的迴歸方法。

對於每個模型，都使用了 `GridSearchCV` 進行超參數的調整，以找到在訓練資料上表現最佳的參數組合。

## 結果

程式碼會輸出每個模型在訓練集和測試集上的評估指標，包括：

* **均方根誤差 (RMSE):** 衡量預測值與實際值之間差異的平方根。
* **平均絕對誤差 (MAE):** 衡量預測值與實際值之間差異的絕對值的平均。
* **平均絕對百分比誤差 (MAPE):** 衡量預測值與實際值之間差異的百分比的平均。

此外，程式碼還會生成以下圖表：

* **實際值 vs. 預測值時間序列圖：** 顯示實際電力需求以及四種模型預測的電力需求隨時間變化的趨勢。
* **預測值 vs. 實際值散點圖：** 顯示每個模型預測值與實際值之間的關係，可以幫助判斷模型的預測偏差。
* **殘差圖：** 顯示每個模型的預測殘差（實際值減去預測值），可以幫助診斷模型的誤差模式。
